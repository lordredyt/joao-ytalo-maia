# João Ytalo Maia — Projeto Amazon

Projeto acadêmico inspirado na interface da Amazon e no projeto Amazon do curso Figma Turbo, com uma seleção de produtos de Star Wars, Senhor dos Anéis e Nintendo.

Site: [joao-ytalo-maia](https://lordredyt.github.io/joao-ytalo-maia/)

## Tecnologias

HTML5, CSS3, JavaScript e VueJS 3 com Options API. Não exige instalação de dependências nem etapa de build.

## Como executar

Abra o arquivo `index.html` no navegador. Para publicar no GitHub Pages, selecione a branch `main` e a pasta raiz `/` em Settings → Pages.

## Funcionalidades

- Página inicial com cards e banners navegáveis.
- Página do Nintendo Switch 2 com sete fotos selecionáveis e ampliação.
- Produtos relacionados, carrinho, quantidade e subtotal demonstrativos.
- Menu lateral, formulário visual de login e rodapé completo.
- Layout adaptado para computadores e celulares.

## Demonstração acadêmica

Este projeto não tem vínculo com Amazon, Nintendo ou Udemy. Preços e avaliações são ilustrativos. Não realiza compras, pagamentos ou autenticação e não envia os dados do formulário de login.

## Créditos

Referência de layout: projeto Amazon do curso Figma Turbo, do professor Ermeson Silva. Imagens de produtos obtidas na Amazon. As marcas e imagens pertencem aos respectivos titulares.
