# Amazon — João Ytalo Maia

Projeto acadêmico do curso Figma Turbo, feito com HTML, CSS, JavaScript, Vue 3.5.42 e Vite. A loja apresenta produtos de Star Wars, Senhor dos Anéis e a página do Nintendo Switch 2.

## Executar

```sh
npm install
npm run dev
```

## Gerar o site

```sh
npm run build
npm run preview
```

Os componentes ficam em `src/components`, os produtos em `src/dados` e o CSS em `src/assets/main.css`. O carrinho e os formulários são demonstrativos.

Marcas e imagens pertencem aos respectivos titulares. Projeto sem vínculo com a Amazon.
